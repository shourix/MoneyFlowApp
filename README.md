# MoneyFlow - 家計予測

**「将来の家計が見える」家計管理アプリ**

給与を入力するだけで手取りを自動計算。毎月の収支から最大24ヶ月先の貯金残高を予測できます。

**[今すぐ使う → https://shourix.github.io/MoneyFlowApp/](https://shourix.github.io/MoneyFlowApp/)**

---

## こんな人におすすめ

- 家計簿はつけているけど、将来いくら貯まるか分からない
- ローンの完済後、生活がどう変わるかイメージしたい
- 残業を増やしたら / 副業を始めたら、手取りがどう変わるか知りたい
- スマホでサクッと支出を記録したい

## 使い方ガイド

### Step 1: まず給与と固定費を入力しよう

**「設定」ページ** を開きます（右端のタブ）。

**収入の設定**
- **額面給与**: 月給の額面（税引前）を入力 → 健康保険・厚生年金・所得税・住民税が自動計算され、手取りが表示されます
- **残業時間**: 月の残業時間を入力 → 残業代が自動計算されます（時給2,273円）
- **ボーナス**: 1回あたりの手取り額を入力（4月・10月に自動反映）
- **副業収入**: 月額の手取りを入力

**支出の設定**
- **固定費** を追加（家賃・光熱費など）
- ローンがある場合は「ローンとして管理」をONにして残り回数を入力 → 完済予定日が自動表示されます
- **変動費** を追加（月の予算として予測に反映）

---

### Step 2: 毎日の支出を記録しよう

画面右下の **＋ボタン（FAB）** をタップすると、どのページからでも支出を記録できます。

1. **金額を入力**
2. **カテゴリを選択**（食材・外食・コンビニ・日用品・交際費・美容など）
3. **メモを入力**（任意）
4. **「記録する」** をタップ

**「記録」ページ** では、カテゴリごとの予算消化率やドーナツチャートで支出の内訳を確認できます。

---

### Step 3: 予測で将来の残高を確認しよう

**「予測」ページ** で将来の家計を確認します。

- 画面上部に **その月末時点の貯金残高** が大きく表示されます
- 左右の矢印で **最大24ヶ月先** まで月をめくれます
- 収入・支出の内訳が月ごとに表示されます（折りたたみ式）
- ローンが完済される月は「完済」と表示され、その分の支出が自動で減ります

グラフの表示期間は 3 / 6 / 12ヶ月 で切り替えられます。

**シミュレーター**（予測ページ内）で、残業時間や副業収入を変えたときの影響をリアルタイムで確認できます。

---

### Step 4: カレンダーで引き落とし日を管理しよう

**「カレンダー」ページ** で、固定費の引き落とし日をカレンダー形式で確認できます。

- 固定費に設定した引き落とし日がカレンダー上にドットで表示されます
- カテゴリ（家賃・ローン・サブスク・光熱費など）でフィルターできます
- 日付をタップすると、その日の引き落とし詳細が表示されます

---

### Step 5: 月末に確定しよう

**「記録」ページ** の一番下にある **「今月を確定する」** ボタンで、月次の収支を確定します。

1. ボタンをタップすると、今月の収支サマリーと予想残高が表示されます
2. 実際の銀行残高を入力します
3. 予想との差額（把握外の支出）が自動計算されます
4. 「確定する」で残高が更新されます

確定するほど翌月以降の予測が正確になります。

## 画面の説明

| ページ | 内容 |
|--------|------|
| **ホーム** | 残高・今月の収支サマリー・1日に使える金額・予算消化ペース・残高予測ミニチャート |
| **記録** | カテゴリ別予算の消化状況・日別支出チャート・支出内訳ドーナツ・月次確定 |
| **予測** | 月別の収支予測（最大24ヶ月）・残高推移グラフ・シミュレーター・ローン情報 |
| **カレンダー** | 固定費の引き落とし日カレンダー・カテゴリフィルター・日別詳細 |
| **設定** | 給与・ボーナス・副業設定、固定費・変動費管理、カテゴリ予算編集、ダークモード、バックアップ |

- スマホでは **左右スワイプ** でページ切り替え
- **＋ボタン**（画面右下）からどこでも支出を記録

## よくある質問

### データはどこに保存されますか？

お使いのスマホ（ブラウザ）の中にだけ保存されます。サーバーには一切送信されません。他の人からデータを見られることはありません。

### 機種変更したらどうなりますか？

データは端末のブラウザに保存されているため、機種変更すると引き継がれません。事前に **バックアップ（エクスポート）** を行い、新しい端末で **インポート** してください。

### 複数人で共有できますか？

URLを共有すれば誰でも使えます。ただし、データは各自の端末に保存されるため、入力内容が他の人に見えることはありません。

---

## バックアップと復元

データの紛失を防ぐために、定期的なバックアップをおすすめします。

### エクスポート（バックアップ）

1. 「設定」ページの **「エクスポート」** ボタンをタップ
2. JSONファイルがダウンロードされます

### インポート（復元）

1. 「設定」ページの **「インポート」** ボタンをタップ
2. バックアップしたJSONファイルを選択
3. 確認画面で「OK」をタップ
