# MoneyFlow - 家計予測

**「将来の家計が見える」家計管理アプリ**

給与を入力するだけで手取りを自動計算。毎月の収支から最大24ヶ月先の貯金残高を予測できます。

**[今すぐ使う → https://shourix.github.io/MoneyFlowApp/](https://shourix.github.io/MoneyFlowApp/)**

---

## こんな人におすすめ

- 家計簿はつけているけど、将来いくら貯まるか分からない
- ローンの完済後、生活がどう変わるかイメージしたい
- 残業を増やしたら / 副業を始めたら、手取りがどう変わるか知りたい
- スマホでサクッと支出を記録したい

## 使い方ガイド

### Step 1: まず給与と固定費を入力しよう

<!-- ![収支入力画面](screenshots/input.png) -->

**「収支入力」タブ** を開きます。

**収入の設定**
- **額面給与**: 月給の額面（税引前）を入力 → 健康保険・厚生年金・所得税・住民税が自動計算され、手取りが表示されます
- **残業時間**: 月の残業時間を入力 → 残業代が自動計算されます（時給2,273円）
- **ボーナス**: 1回あたりの手取り額を入力（4月・10月に自動反映）
- **副業収入**: 月額の手取りを入力

**支出の設定**
- 「支出」タブに切り替え
- 家賃・光熱費などの **固定費** を追加
- ローンがある場合は「ローンとして管理」をONにして残り回数を入力 → 完済予定日が自動表示されます

---

### Step 2: 毎日の支出を記録しよう

<!-- ![家計簿画面](screenshots/spending.png) -->

**「家計簿」タブ** で日々の支出を記録します。

1. **金額を入力**
2. **カテゴリを選択**（朝食代・昼食代・夕飯代・日用品・交際費・美容・その他）
3. **メモを入力**（任意）
4. **＋ボタン** で記録

カテゴリごとに予算を設定しておくと、残り予算や1日に使える金額が自動表示されます。

予算の設定は、画面右上の編集ボタンから行えます。

---

### Step 3: 予測で将来の残高を確認しよう

<!-- ![予測画面](screenshots/forecast.png) -->

**「予測」タブ** で将来の家計を確認します。

- 画面上部に **その月末時点の貯金残高** が大きく表示されます
- 左右の矢印で **最大24ヶ月先** まで月をめくれます
- 収入・支出の内訳が月ごとに表示されます
- ローンが完済される月は「完済」と表示され、その分の支出が自動で減ります

グラフの表示期間は 6 / 12 / 18 / 24ヶ月 で切り替えられます。

---

### Step 4: シミュレーターで「もしも」を試そう

<!-- ![シミュレーター画面](screenshots/simulator.png) -->

**「シミュレ」タブ** で、条件を変えたときの影響を確認できます。

**残業シミュレーター**
- スライダーで残業時間（0〜80時間）を変えると、手取りと残高への影響がリアルタイムで表示されます

**副業シミュレーター**
- 仮の副業収入を入力すると、月末残高への影響が表示されます

どちらもグラフに即座に反映されるので、将来の残高の変化を視覚的に確認できます。

## 画面の説明

| タブ | 内容 |
|------|------|
| **ホーム** | 今月の収支サマリー・月末残高予測・年間貯蓄ペース・収入内訳チャート |
| **収支入力** | 給与・残業・ボーナス・副業の入力、固定費・変動費の管理 |
| **家計簿** | 日々の支出記録、カテゴリ別予算管理、残り予算・1日あたりの使える額 |
| **予測** | 月別の収支予測（最大24ヶ月先）、貯金残高推移グラフ |
| **シミュレ** | 残業時間・副業収入を変えたときの手取りと残高のシミュレーション |
| **ローン** | ローン一覧・完済カウントダウン・完済後の月間余剰金 |

## よくある質問

### データはどこに保存されますか？

お使いのスマホ（ブラウザ）の中にだけ保存されます。サーバーには一切送信されません。他の人からデータを見られることはありません。

### 機種変更したらどうなりますか？

データは端末のブラウザに保存されているため、機種変更すると引き継がれません。事前に **バックアップ（エクスポート）** を行い、新しい端末で **インポート** してください。

### 複数人で共有できますか？

URLを共有すれば誰でも使えます。ただし、データは各自の端末に保存されるため、入力内容が他の人に見えることはありません。

## バックアップと復元

データの紛失を防ぐために、定期的なバックアップをおすすめします。

### エクスポート（バックアップ）

1. 「ホーム」タブの一番下にある **「エクスポート」** ボタンをタップ
2. JSONファイルがダウンロードされます

### インポート（復元）

1. 「ホーム」タブの一番下にある **「インポート」** ボタンをタップ
2. バックアップしたJSONファイルを選択
3. 確認画面で「OK」をタップ
